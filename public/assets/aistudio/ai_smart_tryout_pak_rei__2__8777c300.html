Arsitektur Pencegah Kebocoran API Key (Anti-Leak):
  • Zero Hardcoded Plaintext: File HTML ini 0% menyimpan teks API Key mentah di dalam source code, sehingga aman dari scanner otomatis GitHub/Google Cloud saat file dibagikan.
  • Header-Only Transport: Key dikirim via header x-goog-api-key (bukan URL ?key=) dengan referrerPolicy: no-referrer & bisa berjalan langsung dari file:// lokal.
  • Enkripsi AES-256-GCM: Opsional kunci dengan PIN atau ekspor menjadi Token Terenkripsi yang aman ditempel.
